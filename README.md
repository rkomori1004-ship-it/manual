# 開店・締め作業記録アプリ（PWA版）セットアップ

このフォルダを Web に置くと、iPad のホーム画面に「専用アプリ」として追加できるようになります。

## 中身
- `index.html` … アプリ本体
- `manifest.webmanifest` … アプリ情報（名前・アイコン）
- `sw.js` … オフラインでも開けるようにする仕組み
- `icon-*.png` / `apple-touch-icon.png` … アイコン画像

**フォルダの中身を丸ごと**同じ場所に置いてください。1つでも欠けると正しく動きません。

---

## いちばん簡単な公開方法：GitHub Pages（無料）

れーおさんは既に GitHub Pages を使っているので、同じ流れです。

1. GitHub で新しいリポジトリを作る（例：`musubi-ops`）
2. このフォルダ内の**すべてのファイル**をアップロード
   （`index.html` がリポジトリの一番上の階層に来るようにする）
3. リポジトリの Settings → Pages → Branch を `main` / `root` にして保存
4. 数分後に `https://ユーザー名.github.io/musubi-ops/` で開けるようになる

> PWA（ホーム画面追加＋オフライン）は **https で開いたときだけ**有効です。
> GitHub Pages は自動で https になるので条件を満たします。

---

## iPad のホーム画面に追加する

1. **Safari** で上記の URL を開く（Chrome ではなく Safari を使ってください）
2. 下の共有ボタン（□に↑）をタップ
3. 「ホーム画面に追加」を選ぶ
4. ホームに「作業記録」アイコンが追加される

以降はそのアイコンから、Safari のバーが消えた全画面で開けます。
スタッフには「このアイコンを押すだけ」で使ってもらえます。

---

## 使うときの注意（重要）

- **アラームはアプリを開いている間だけ鳴ります。** iPad の仕様で、画面オフ・スリープ中や他アプリに切り替えている間は鳴りません。
  → 確実に鳴らしたい時刻（10:45・19:55 など）は、iPad 標準の「時計」アプリでもアラームをセットしておくと安心です。
  → 設定 → 画面表示と明るさ → 自動ロック「しない」にして、レジ横で開きっぱなしにするのがおすすめです。
- **記録はその iPad の中に保存されます。** 複数台で使うと台ごとに履歴が分かれます。集計をまとめたいときは、アプリの設定タブ →「書き出す（CSV）」でファイルを出してください。
- iPad の縦・横は自動で切り替わります。どちらの向きでも使えます。

## 音を出すには
右上の「🔕 音オフ」を一度タップして「🔔 音オン」にしてください（タップのたびに切り替わります）。
iPad は一度画面をタッチしないと音を出せない仕様のため、開店時に一度押す運用になります。
